# 📝 이유민 TO-DO LIST

> **"오늘 한 일이 내일의 나를 만든다."**  
> 매일의 목표를 기록하고 달성률을 확인하며 스스로를 성장시키는 모바일 맞춤형 투두리스트 웹 서비스입니다.

---

## 🌟 주요 기능 (Key Features)

- **실시간 날짜 & 시각 표시**: 상단에 현재 날짜와 시각이 실시간으로 업데이트됩니다.
- **달성률(%) 게이지바**: 체크박스를 선택할 때마다 실시간으로 달성 퍼센트와 게이지바가 채워집니다.
- **100% 달성 축하 메시지**: 모든 할 일을 마치면 `Clear!` 메시지가 뜹니다.
- **일일 동기부여 문구**: 날짜별로 매일 새로운 동기부여 명언이 하단에 업데이트됩니다.
- **데이터 자동 저장 (LocalStorage)**: 브라우저를 새로고침하거나 종료해도 내가 작성한 할 일과 체크 상태가 유지됩니다.
- **원클릭 Reset 기능**: Reset 버튼을 통해 한 번에 모든 목록을 초기화할 수 있습니다.
- **모바일 최적화 반응형 UI**: 미니멀하고 직관적인 흑백 톤의 디스플레이 디자인을 제공합니다.

---

## 🛠 사용 기술 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Deployment**: GitHub Pages
